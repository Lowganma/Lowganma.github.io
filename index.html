Proyectos & Devlog

Inventario_v1

Django · Python · Bootstrap · SQLite

Sistema Open Source de gestión comercial pensado para pequeños negocios que necesitan controlar inventario, ventas, clientes y caja sin depender de costosas suscripciones.

Funciona dentro de la red Wi-Fi del negocio y puede utilizarse desde computadoras, tablets o teléfonos.

Achantes

Godot 4 · GDScript · Blender · Android
