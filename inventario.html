Inventario_v1

Sistema Abierto de Gestión Comercial Local

Una herramienta pensada para que un pequeño negocio pueda controlar ventas, inventario, clientes y caja sin depender de costosas suscripciones ni de una conexión permanente a Internet.

La idea es sencilla: convertir cualquier computadora del negocio en el centro de un sistema accesible desde teléfonos, tablets y laptops conectados a la misma red Wi-Fi.

  • Ver código en GitHub

01. El problema

En Venezuela y en buena parte de Latinoamérica, muchos pequeños emprendimientos todavía administran sus productos, ventas y cuentas con lápiz, papel, cuadernos o archivos de Excel independientes.

El problema no necesariamente es la falta de tecnología. Muchas soluciones comerciales existentes están pensadas para empresas con mayor presupuesto, requieren pagos mensuales, suscripciones en dólares, conectividad permanente o procesos de configuración demasiado complejos para un pequeño comercio.

Esto crea una situación frecuente: el comerciante necesita digitalizarse, pero la herramienta termina siendo más difícil de administrar que el propio negocio.

¿Y si el sistema pudiera instalarse en una computadora, funcionar dentro del propio local y ser consultado desde cualquier dispositivo conectado a su Wi-Fi?

02. La solución

Inventario_v1 es un sistema de gestión comercial construido sobre Django que puede ejecutarse dentro de la red local del negocio.

La computadora principal funciona como servidor local y los demás dispositivos pueden acceder al sistema mediante el navegador. De esta manera, un trabajador puede registrar una venta desde un teléfono mientras otra persona revisa el inventario desde una laptop.

Productos

Registro y administración de productos disponibles dentro del negocio.

Ventas

Registro de operaciones comerciales con actualización de inventario.

Clientes

Organización de información básica relacionada con los compradores.

Caja Chica

Control de movimientos cotidianos de dinero dentro del negocio.

04. Arquitectura & Stack Tecnológico

🐍 Python

Lenguaje principal del backend. Permite mantener una base de código clara, escalable y ampliamente documentada.

⚙️ Django

Framework principal utilizando arquitectura MVT. Se encarga de modelos de datos, lógica del negocio, vistas, seguridad y administración.

📱 Bootstrap

Permite construir una interfaz responsive que pueda utilizarse desde computadoras, tablets y teléfonos.

🗄️ SQLite / PostgreSQL

SQLite facilita instalaciones locales pequeñas, mientras PostgreSQL permite escalar el sistema cuando el proyecto requiera una infraestructura mayor.

🐳 Docker

El objetivo de distribución es empaquetar el sistema para reducir al mínimo los pasos necesarios para instalarlo y ejecutarlo.

06. ¿Por qué Open Source?

Inventario_v1 busca ser una herramienta accesible para pequeños comerciantes que normalmente no pueden justificar el costo mensual de un software empresarial.

El objetivo del proyecto es mantener una versión abierta que pueda instalarse, estudiarse y mejorarse libremente.

El patrocinio permitiría dedicar más tiempo al desarrollo, documentación, empaquetado y mantenimiento sin trasladar esos costos a los comerciantes que utilizan la herramienta.
