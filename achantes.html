Achantes

Espacio Virtual Colaborativo en Tiempo Real

Un lugar digital para entrar, relajarse, crear y compartir con otras personas sin convertir cada encuentro en una reunión formal.

Achantes combina interacción social, dibujo colaborativo y contenido sincronizado dentro de salas virtuales personalizables.

01. El problema

Discord, Zoom y otras plataformas permiten hablar, transmitir pantalla o escribir mensajes, pero la experiencia continúa organizada alrededor del concepto tradicional de llamada o reunión.

Para artistas, creadores de contenido, dibujantes o grupos de amigos, eso deja un espacio interesante sin cubrir: un entorno donde las personas puedan simplemente pasar el rato mientras realizan actividades conjuntamente.

La intención de Achantes no es organizar una reunión. Es crear un lugar digital donde puedan suceder cosas.

02. La solución

Achantes propone salas virtuales donde diferentes experiencias conviven dentro del mismo espacio.

🎨 Canvas colaborativo

Los usuarios pueden dibujar conjuntamente y observar los cambios de los demás participantes en tiempo real.

🖱️ Cursores sincronizados

La posición e interacción de diferentes participantes puede visualizarse dentro del espacio compartido.

🎵 Audio compartido

Los integrantes de una sala pueden escuchar contenido de manera sincronizada.

🏠 Salas personalizables

Cada comunidad puede tener su propio espacio y evolucionar hacia una identidad independiente.

03. Demostración

El prototipo actual demuestra sincronización de salas, cursores, lienzo colaborativo y reproducción de contenido.

Espacio preparado para incluir el GIF o video real del prototipo.

04. Arquitectura & Stack Tecnológico

TypeScript

Permite desarrollar una aplicación web compleja con tipado estático y mejor control de estructuras, eventos y estados.

Supabase

Proporciona autenticación, base de datos relacional y servicios de sincronización en tiempo real.

WebSockets / Realtime

Permiten transmitir eventos rápidamente entre los participantes de una misma sala.

HTML5 Canvas

Base gráfica del sistema colaborativo de dibujo y experimentación visual.

06. Roadmap

  • Integraciones musicales: conectar servicios y APIs para ampliar la experiencia de escucha compartida.
  • Salas persistentes: crear espacios permanentes para comunidades.
  • Comunidades de streamers: entornos personalizados para creadores de contenido.
  • Sistema de permisos: administradores, colaboradores, artistas e invitados.
  • Persistencia creativa: guardar lienzos y actividades realizadas dentro de cada sala.

Ayuda a construir Achantes

Una plataforma colaborativa en tiempo real necesita infraestructura disponible continuamente.

El apoyo al proyecto permitirá cubrir servidores, servicios de Supabase, almacenamiento y mantenimiento a medida que aumente el número de usuarios.
